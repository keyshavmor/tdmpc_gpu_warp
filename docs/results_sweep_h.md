# Horizon sweep: CPU MuJoCo baseline vs GPU port

*tdmpc_gpu_warp: GPU port of TD-MPC by Keyshav Mor. Based on TD-MPC by Nicklas Hansen, Xiaolong Wang and Hao Su (https://github.com/nicklashansen/tdmpc).*

Steady-state cost per agent step (plan + env step + one update) and peak process VRAM, single run alone on the RTX 3090.
Modes: **cpu** = original code (CPU MuJoCo 2.1 / dm_control, agent on GPU, torch 2.4.1); **gpu** = faithful mujoco_warp port (original eager agent, torch 2.11); **gpu_opt** = GPU port + CUDA-graph agent + host pacing.
Speed-up = cpu time / mode time. VRAM = whole process as reported by nvidia-smi (CUDA context + buffers + allocator cache).
